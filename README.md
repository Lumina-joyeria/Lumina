# LÚMINA — Sistema de Gestión para Joyería

LÚMINA es una aplicación web para la gestión de una joyería, desarrollada como proyecto académico de Programación Web.

El sistema busca integrar la administración de productos, categorías, clientes y pedidos con una tienda en línea de diseño moderno y elegante.

## Tecnologías

- **Backend:** PHP 8.3 y Laravel 13.
- **Base de datos:** MySQL.
- **Frontend:** HTML, CSS, JavaScript y Blade.
- **Entorno de desarrollo:** Laragon.
- **Control de versiones:** Git y GitHub.

## Funcionalidades implementadas

- Inicio y cierre de sesión.
- Autenticación de usuarios.
- Protección de rutas y control de acceso por roles.
- Registro, consulta, actualización y eliminación de categorías.
- Validación de formularios.
- Protección para evitar la eliminación de categorías con productos asociados.

## Funcionalidades en desarrollo

- Gestión de productos e inventario.
- Administración de clientes.
- Gestión de pedidos y ventas.
- Tienda en línea e integración del frontend.
- Reportes y movimientos financieros.

## Estado del proyecto
